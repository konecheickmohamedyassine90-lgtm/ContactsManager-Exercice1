# ContactsManager 

## Description
Application Java de gestion de contacts.

## Fonctionnalités
- Ajouter des contacts (nom + numéro de téléphone)
- Rechercher un contact par nom
- Afficher le numéro de téléphone d'un contact

## Structure du projet
- Contact.java : classe représentant un contact
- ContactsManager.java : classe gérant la liste de contacts
- Main.java : point d'entrée du programme

## Comment exécuter
1. Ouvrir le projet dans IntelliJ IDEA
2. Exécuter la classe Main.java
3. Le programme affiche le numéro de Jean
